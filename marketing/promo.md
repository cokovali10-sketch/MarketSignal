# Маркетинг MarketSignal 📈

Готовые материалы для продвижения бота. Размещайте их **вручную** в чатах
продавцов маркетплейсов, где это разрешено правилами (анонсы, «поделиться опытом»).
**Не делайте массовый спам** — это заблокирует и вас, и бота.

---

## 1. Описание бота для @BotFather

Отправьте боту @BotFather:
- `/setdescription` → @marketsssignal_bot →

```
Telegram-бот для продавцов Wildberries и Ozon. Следит за ценами конкурентов, показывает остатки, строит графики, ловит момент выгодной цены и подсказывает, что завезти. Оплата в одну кнопку (Telegram Stars). Бесплатный старт.
```

- `/setabouttext` → @marketsssignal_bot →

```
Аналитика WB/Ozon для продавцов: цены, остатки, графики, идеи для завоза.
```

- `/setuserpic` → загрузите `assets/avatar.png`

- `/setcommands` →

```
start - Главное меню
now - Мои товары
digest - Дайджест цен
help - Помощь
```

## 6. План продвижения (бесплатно)

1. **Свои знакомые-продавцы** — покажите бота лично, попросите попробовать.
2. **Профильные Telegram-чаты** — ищите «чат продавцов Wildberries», «продавцы Ozon». Внимательно читайте правила: во многих есть тема «самопродвижение». Размещайте пост №2 только там, где это разрешено.
3. **Отвечайте на вопросы** — в чатах новички спрашивают «как отслеживать цену конкурента». Пост №4 — идеальный ответ.
4. **Один клиент → рекомендация** — реферальная ссылка даёт вам +3 дня подписки за каждого, кто оплатит по вашей ссылке.
5. **Канал-анонсы ботов** — в Telegram есть каналы «новые боты», где принимают заявки бесплатно. Напишите автору такого канала.

## 7. Почему нельзя спамить

- Telegram массово банит аккаунты за рассылку непрошенных сообщений.
- WB/Ozon блокируют за спам по их пользователям.
- Массовые рассылки в чаты против правил — вас кикнут, бота заблокируют.
- Хорошая новость: **ботам из ниши платят за результат**. Один довольный клиент расскажет о боте десяти другим — это бесплатная реклама, которая реально приносит деньги.
